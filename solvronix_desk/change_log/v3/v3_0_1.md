## Version 3.0.1

### Fixed

- **Apps with their own screen** — in the Icon Rail, apps such as CRM now open their own
  page instead of showing "Page not found" inside the Desk.
- **Notifications** — opening a notification marks it read, read notifications no longer
  come back as unread after a reload, and the bell's number now matches what is really unread.
- **All Apps** — if some workspaces are hidden by your module settings, the page now tells
  you how many, so nothing seems to be missing without a reason.
- Checked with the latest Frappe and ERPNext version 16 updates.
